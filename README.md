## Description
SimulinkClone is a simple F# application for visual block-based modeling and simulation, similar to Simulink. Users can create diagrams using blocks (Constant, Gain, Integrator, Add), connect them, and run simulations with results displayed as graphs.

## Getting Started:
### 1. Clone the repository
   git clone [https://github.com/YOUR_USERNAME/YOUR_REPO.git](https://github.com/cbatelic/project.git)
   cd YOUR_REPO

### 2. Run the backend (API)
   cd SimulinkClone.Service
   dotnet run

### 3. Run the frontend (App)
   cd SimulinkClone.App
   dotnet run

### 4. Use the application
   - Add blocks from the Toolbox
   - Connect them (output → input)
   - Click Run
   - View simulation results in the graph window
